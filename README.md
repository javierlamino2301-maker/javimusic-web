javimusic-web
Página web interactiva sobre música creada con HTML, CSS y JavaScript. Incluye efectos visuales, animaciones y recursos JavaScript interactivos.
Ver la página en vivo

Descripción
Web de comunidad musical con registro de usuarios, galería interactiva de imágenes, personalización de mensajes y efectos de movimiento.
Estética inspirada en Spotify y Apple Music: diseño moderno con gradientes, efectos glassmorphism y animaciones suaves.

Recursos JavaScript
1. Intercambio de imágenes al hacer clic
Galería con 3 imágenes que cambian al hacer clic. Cada imagen tiene 3 variaciones diferentes.
2. Campo de texto dinámico
Input que actualiza en tiempo real un mensaje personalizado en la página.
3. Objetos en movimiento
Notas musicales flotantes que se generan automáticamente y se mueven por la pantalla con animaciones CSS.
